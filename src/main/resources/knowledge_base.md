# HookFi FAQ 知識庫

## API Key 綁定教學
<!-- tags: api key,apikey,綁定,幣安,binance,key,secret -->
### 如何綁定 Binance API Key？
1. 登入 [Binance](https://www.binance.com)，前往「API 管理」
2. 建立新 API Key，命名如「HookFi」
3. 開啟權限：「啟用合約」（Enable Futures）和「讀取」（Read）
4. **不要開啟**「啟用提現」（Enable Withdrawals）
5. 建議設定 IP 白名單（HookFi 伺服器 IP）
6. 複製 API Key 和 Secret Key
7. 到 HookFi 網站 → 個人設定 → API Key → 貼上 Key 和 Secret → 儲存
8. 系統會用 AES-256-GCM 加密儲存，不保留明文

**注意事項：**
- 只需要合約（Futures）權限，不需要現貨權限
- Secret Key 只會顯示一次，請妥善保存
- 如果 Key 無效，請重新建立

## LINE 綁定流程
<!-- tags: line,綁定,通知,連結碼,連結 -->
### 如何綁定 LINE 通知？
1. 到 HookFi 網站 → 通知設定 → 點擊「產生 LINE 連結碼」
2. 系統會產生一組 6 位數連結碼（10 分鐘內有效）
3. 加入 HookFi LINE 官方帳號為好友
4. 在 LINE 對話中輸入該連結碼
5. 綁定成功後，交易通知會同時推送到 Discord 和 LINE

**注意事項：**
- 連結碼 10 分鐘後過期，需重新產生
- 一個 LINE 帳號只能綁定一個 HookFi 帳號
- 可在通知設定中解除綁定

## 風控參數說明
<!-- tags: 風險,風控,槓桿,leverage,dca,層數,比例,止損,止盈,risk -->
### 風控參數是什麼？
HookFi 提供四項可調整的風控參數：

1. **風險比例**（Risk Percent）：每筆交易使用的帳戶比例（0.01~1.0）
   - 例如 0.3 = 每筆用 30% 可用餘額
   - 建議新手設 0.1~0.2（10%~20%）

2. **最大槓桿**（Max Leverage）：交易最高槓桿倍數（1~125 倍）
   - 實際槓桿由訊號決定，此為上限
   - 建議不超過 20 倍

3. **DCA 層數**（Max DCA Layers）：加碼次數上限（0~10 層）
   - 0 = 不加碼，1 = 最多加碼一次
   - DCA 會在虧損時加碼攤平成本

4. **自動止損/止盈**（Auto SL/TP）：是否自動設定止損止盈
   - 開啟後系統會依訊號自動設置
   - 建議保持開啟

你可以直接在對話中告訴 AI 客服修改，例如：「幫我把風險比例改成 20%」

## 訂閱方案說明
<!-- tags: 訂閱,方案,plan,付費,價格,免費,升級,到期 -->
### HookFi 訂閱方案
- **免費方案**：可查看 Dashboard，但無法自動跟單
- **Pro 方案**：啟用自動跟單、即時通知、AI 顧問分析
- **Lifetime 方案**：永久使用所有功能

只有 ACTIVE 或 LIFETIME 訂閱狀態才能啟用自動跟單。
訂閱到期後會自動停止跟單，但不會關閉已開啟的倉位。

## 跟單機制與訊號流程
<!-- tags: 跟單,訊號,流程,怎麼跟,自動,下單,機制,延遲,速度 -->
### 訊號跟單流程
1. **訊號來源**：KOL 在 Discord 頻道發出交易訊號
2. **訊號擷取**：Python Monitor 監聽頻道，解析訊號內容（幣種、方向、價格、止損/止盈）
3. **訊號傳送**：透過 REST API 送到 HookFi 後端
4. **去重檢查**：三層去重確保不重複下單
   - Signal hash（5 分鐘內同一訊號）
   - message_id 永久去重
   - Per-user execution 去重
5. **廣播下單**：對所有有效訂閱用戶，用各自的 API Key 平行下單
   - 批次 15 人，每批間隔 200ms
6. **結果通知**：下單成功/失敗透過 Discord + LINE 通知

**延遲說明**：從訊號發出到下單完成，通常在 1~3 秒內。

## 常見問題
<!-- tags: 問題,未成交,沒跟到,強平,延遲,失敗,異常,沒有開 -->
### 為什麼訊號沒有跟到？
可能原因：
1. **訂閱未啟用**：確認訂閱狀態為 ACTIVE 或 LIFETIME
2. **API Key 無效**：Key 過期或被 Binance 撤銷，需重新綁定
3. **餘額不足**：合約帳戶可用餘額不夠開倉
4. **去重機制**：同一訊號 5 分鐘內不會重複下單
5. **槓桿限制**：訊號要求的槓桿超過你設定的最大槓桿

### 為什麼被強制平倉（強平）？
- 帳戶保證金不足時，幣安會強制平倉
- 高槓桿 + 大倉位 + 大幅波動 = 強平風險高
- 建議：降低槓桿、控制風險比例、開啟自動止損

### 交易延遲怎麼辦？
- 正常延遲 1~3 秒，市場劇烈波動時可能 3~5 秒
- 如超過 10 秒，可能是 API 連線問題，請回報異常

## 績效報表說明
<!-- tags: 績效,報表,dashboard,勝率,損益,pnl,報告 -->
### 如何查看交易績效？
1. 登入 HookFi 網站 → Dashboard → 績效總覽
2. 可查看：總交易數、勝率、總損益（PnL）
3. 每筆交易詳情：幣種、方向、入場/出場價、手續費、淨利
4. 支援按時間範圍篩選

### AI 訊號日報
- 系統每日自動生成訊號分析報告
- 包含：當日訊號數、多空比例、AI 信心分數
- 可透過 AI 客服查詢：「今天的訊號日報」

## 通知設定
<!-- tags: 通知,discord,line,webhook,推播,設定 -->
### 通知頻道
HookFi 支援兩種通知頻道：
1. **Discord**：透過 Webhook 推送到指定頻道
2. **LINE**：透過 LINE Messaging API 推送私人訊息

### 通知類型
- **交易通知**：開倉/平倉成功、止損/止盈觸發
- **系統通知**：訂閱到期提醒、API Key 問題警告
- **Admin 通知**：風控告警、系統異常、廣播彙總報告

### 如何設定？
- Discord：預設啟用（綁定帳號後自動推送）
- LINE：需先完成 LINE 綁定流程（見上方教學）

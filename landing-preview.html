服務條款與隱私政策

請閱讀以下條款

1. 服務說明
HookFi 提供加密貨幣自動交易服務，透過 API 與幣安等交易所整合。本服務僅供資訊與工具用途，不構成投資建議。


2. 風險揭露
加密貨幣交易具有高風險，可能導致部分或全部投資損失。過去的績效不代表未來的結果。您應僅以可承受損失的資金進行交易。


3. 非託管架構
HookFi 不持有您的資金。所有交易透過您自己的幣安帳戶執行。您的 API 金鑰以 AES-256 加密儲存，我們無法提取您的資產。


4. 隱私政策
我們收集的個人資料僅用於提供服務。您的資料不會出售給第三方。詳細資訊請參閱完整隱私政策頁面。


5. 免責聲明
HookFi 不對因使用本服務而產生的任何交易損失負責。使用自動交易功能即表示您了解並接受相關風險。

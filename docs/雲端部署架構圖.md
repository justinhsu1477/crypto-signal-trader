## Port 總覽

### 對外 (Droplet → Internet)
| Port | 服務 | 說明 |
|------|------|------|
| 80/tcp | Caddy | Cloudflare Flexible 模式連入 |
| 443/tcp | Caddy | 保留（目前未使用） |

### Docker 內部 (容器互通)
| Port | 服務 | 說明 |
|------|------|------|
| 8080 | trading-api | Spring Boot API |
| 3000 | web-dashboard | Next.js 前端 |
| 2019 | Caddy admin | 僅 localhost |

### 外連 (Droplet → 外部)
| Port | 目標 | 說明 |
|------|------|------|
| 5432 | Neon PostgreSQL | JDBC + SSL |
| 443 | Binance REST API | 下單、查詢 |
| 443 | Binance WebSocket | 即時倉位監控 |
| 443 | Discord Webhook | 交易通知推送 |
| 443 | Google Gemini API | AI 顧問分析 |
| 443 | Resend Email API | Email OTP 驗證 |

## 排程任務 (Cron)
| 時間 | 功能 |
|------|------|
| 每天 07:55 | 日報預檢 |
| 每天 08:00 | 每日 PnL 報告 → Discord |
| 每天 03:00 | 清理過期 Email OTP |
| 每 30 分鐘 | Binance WebSocket keepalive |
| 每 60 秒 | Monitor 心跳檢查 |
| 每 4 小時 | Gemini AI 顧問分析 |
| 每 5 分鐘 | Rate Limit 清理 |

## 部署指令
```bash
# 更新部署
cd /root/crypto-signal-trader
git pull
docker compose -f docker-compose.cloud.yml up -d --build

# 查看狀態
docker compose -f docker-compose.cloud.yml ps

# 查看 log
docker compose -f docker-compose.cloud.yml logs -f trading-api
```
